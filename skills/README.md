# Skills Directory

This directory contains reusable patterns and setup guides for AI/ML projects in this repository.

## Available Guides

### [PROJECT-SETUP-GUIDE.md](PROJECT-SETUP-GUIDE.md)
Comprehensive guide for setting up new AI/ML projects covering:
- Machine Learning projects (TensorFlow, Keras)
- LangChain Agent projects
- RAG (Retrieval-Augmented Generation) systems
- FastAPI services

The guide includes:
- Project structure templates
- Configuration file templates (`pyproject.toml`, `.env`, `.gitignore`)
- Code structure patterns for each project type
- Best practices and common patterns
- Quick start commands
- Troubleshooting tips

## Usage

When starting a new project in this repository:

1. Review the [PROJECT-SETUP-GUIDE.md](PROJECT-SETUP-GUIDE.md)
2. Choose the appropriate project type template
3. Copy the relevant configuration files
4. Follow the setup steps
5. Adapt the code structure pattern to your needs
